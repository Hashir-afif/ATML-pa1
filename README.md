# PA1: Beyond IID (EE-5102 / CS-6304 Advanced Topics in Machine Learning)

The code, configurations and machine-readable results for Programming Assignment 1. The assignment
manual is `ATML-PA1.pdf`.

| Task | Topic | Status |
|---|---|---|
| 1 | Inductive biases and feature representations (STL-10; ResNet-50, ViT-B/16, CLIP) | implemented |
| 2 | Unsupervised domain adaptation (PACS → Sketch; Source-only, DAN, DANN, CDAN) | not started |
| 3 | Domain generalization (PACS, Sketch unseen; ERM, DAN-DG, SAM) | not started |
| 4 | Open-set recognition (CIFAR-10 known / CIFAR-100 near + far unknowns) | not started |

## Repository structure

```
README.md  requirements.txt  .gitignore
task1/            notebooks 00-07, configs/, results/ (working copies), README.md
task2/ task3/ task4/   (added as each task is implemented)
results/
  task1/ ...      final machine-readable results per task (+ consolidated results.json)
  report.md       factual experiment log / evidence notebook (NOT the submitted report)
figures/
  task1/ ...      final figures per task (PNG + PDF)
```

## Environment

The code needs Python 3.12 and a CUDA GPU (recommended). It was tested on an RTX 4060 Laptop with CUDA 12.8 wheels.

```bash
uv venv --python 3.12
uv pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cu128 --extra-index-url https://pypi.org/simple
.venv/Scripts/python -m ipykernel install --user --name pa1 --display-name "Python (pa1 .venv)"
```

## Running

Each task has its own README with exact commands. Task 1: see [task1/README.md](task1/README.md).

## Results

- Machine-readable results are in `results/taskN/`. Task 1 also has a nested `results/task1/results.json`.
- Figures are in `figures/taskN/`.
- `results/report.md` is a factual evidence log. Every number in it traces to a file in `results/`.

## Reproducibility

Seed 6304 is used wherever the manual specifies it. Every split, subset ID list, permutation and
configuration is saved next to the results. Large caches and checkpoints are git-ignored and are
regenerated by running the notebooks.

## External code attribution

- Task 1 AdaIN style transfer: adapted from <https://github.com/naoto0804/pytorch-AdaIN>, with
  pretrained weights from its release. See [task1/README.md](task1/README.md).
- Pretrained models come from torchvision and OpenCLIP.
